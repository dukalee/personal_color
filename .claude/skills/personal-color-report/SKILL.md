# 퍼스널 컬러 리포트 작업 절차

## 0. 사진 확인
얼굴 사진이 없으면 아래 문장만 출력하고 종료:
`퍼스널 컬러 진단을 위해 얼굴이 잘 보이는 사진을 먼저 업로드해주세요.`

## 1. 관찰
피부톤, 머리카락, 눈동자, 전체 대비감, 조명 왜곡 가능성을 확인한다. (`docs/diagnosis-criteria.md`)

## 2. 진단
봄 웜톤 / 여름 쿨톤 / 가을 웜톤 / 겨울 쿨톤 중 **하나**를 선택한다.

## 3. 컬러 선정
`data/seasons.json`에서 해당 계절의 `best` 5개, `worst` 5개를 가져온다.

## 4. 의상 이미지 5개 생성
`docs/outfit-generation.md` 조건에 따라 얼굴을 유지한 전신 정면 이미지 5개를 만든다.

## 5. 리포트 조립
`docs/report-layout.md` 구성대로 하나의 PNG로 합성하고 `output/personal-color-report.png`에 저장한다.

## 6. 응답
PNG 리포트 1장만 제공한다. 추가 설명 문장은 쓰지 않는다.
