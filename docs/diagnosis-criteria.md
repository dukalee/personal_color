# 진단 기준

## 관찰 요소 (종합 판단)

- 피부색, 노란기/붉은기/푸른기
- 얼굴 전체의 명도와 채도
- 눈동자 색
- 머리카락 색
- 인상의 선명도 또는 부드러움 (대비감)
- 사진 조명·보정으로 인한 색 왜곡 가능성

조명/보정 때문에 판단이 제한되더라도, 가능한 범위에서 **가장 적합한 유형 하나**를 선택한다. "판단 불가"로 끝내지 않는다.

## 판정 흐름

1. 웜 vs 쿨: 피부 언더톤(노란기 ↔ 푸른/핑크기), 머리·눈동자의 따뜻함/차가움
2. 명도·채도·대비로 계절 결정
   - 웜 + 밝고 투명, 맑음 → **봄 웜톤**
   - 웜 + 깊고 차분, 탁함 → **가을 웜톤**
   - 쿨 + 부드럽고 밝음, 흰빛·회색기 → **여름 쿨톤**
   - 쿨 + 선명하고 대비 강함 → **겨울 쿨톤**

유형별 특징·어울리는 색 설명은 `data/seasons.json`을 따른다.

## 금지

- 4가지 외 결과 생성 금지. 판단 과정은 12톤(계절별 3종)을 쓰되 리포트 타이틀은 4계절, 세부 톤은 타이틀 아래 보조 라벨로 표시
- 진단 지침 원문: `src/lib/openai/diagnose.ts`
- 체형·외모·매력도 평가 금지
