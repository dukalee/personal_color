# 리포트 구성 및 디자인

결과는 **5페이지 슬라이드**로 화면에만 보여준다 (1200×900 고정, 화면에서는 카드 폭 1160px에 맞춰 표시, 계절 테마 적용). 다운로드·탭 버튼은 없고, 좌우 이동은 슬라이드 양옆 화살표(및 스와이프·←→ 키)로만 한다. 모든 텍스트는 한국어.
구현: `src/components/slides.tsx`(슬라이드), `Deck.tsx`(좌우 화살표·스와이프·←→ 키)

## 페이지 구성

| 페이지 | 내용 |
|---|---|
| 1. 요약 | 제목 "Personal Color Report" + 사용자 사진(작게) + 리본 "당신의 퍼스널 컬러는" + 진단 결과 `label`(가장 크게) + 세부 톤 + 한 줄 설명 + 키워드 4개 + 지표 4칸(언더톤/명도/채도/대비) + 총평 + 푸터(날짜·신뢰도·안내) |
| 2. 어울리는 색 | `best` 5종 큰 색상칩(이름+HEX) + **추천 컬러 조합 3개**(`combos.best`: 두 색 + 설명) |
| 3. 피해야 하는 색 | `worst` 5종 색상칩(✕ 표시) + **피해야 할 컬러 조합 3개**(`combos.avoid`: 두 색 + 이유 + "대신" 추천 조합) |
| 4~5. 추천 스타일링 1~2 | 전신 이미지 + 룩 이름 + 사용 컬러 + 상의·하의·신발·액세서리 설명 (`docs/outfit-generation.md`) |

- 컬러 조합은 `data/seasons.json`의 `combos`가 `best`/`worst` 배열의 인덱스로 참조한다 (컬러 값은 중복 정의하지 않는다).
- 스타일링 2개가 모두 생성된 뒤에만 결과 슬라이드를 보여준다.

## 디자인 지침

- 깔끔하고 고급스러운 뷰티 컨설팅 스타일
- 전체 색감(배경·포인트)은 진단된 계절 팔레트에 맞춰 조화롭게 (`src/lib/theme.ts`)
- 추천/회피는 시각적으로 구분 (회피 색상칩은 ✕ 표시)
- 설명 문장은 최소화, 핵심 정보 중심
- 텍스트 가독성 확보 (배경과 충분한 대비, Noto Sans/Serif KR)

## 구현 메모

- 컬러/라벨/조합은 `data/seasons.json`에서 로드
